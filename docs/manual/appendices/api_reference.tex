% Long monospaced identifiers leave little room for line breaking; allow some

\begingroup\setlength{\emergencystretch}{3em}% chapter-local

This appendix lists the public classes and functions of version 1.2 with their
signatures, grouped by module. Signatures omit type annotations; defaults are
shown as in the source code. The chapters give the semantics, and the
docstrings (\code{help(obj)} in Python) give full details. Names that start
with an underscore and modules not listed here are internal and may change
without notice; the one exception are the documented hooks of
\code{BatchedVectorEnv} (Section~\ref{sec:api-vector}), which subclasses
implement.

\section{\texorpdfstring{\pkg{env\_lib}}{env\_lib}}\label{sec:api-envlib}

\subsection{Package functions}

% norun
\begin{pycode}
env_lib.make(env_id, **kwargs) -> gym.Env
env_lib.make_vec(env_id, num_envs=1, vectorization_mode=None, *,
                 autoreset_mode=None, vector_kwargs=None, wrappers=None,
                 **kwargs) -> gym.vector.VectorEnv
env_lib.get_spec(env_id) -> EnvSpec
env_lib.list_envs() -> list[str]
env_lib.register_envs()
env_lib.__version__                       # "1.2.0"
env_lib.ResetNeededError                  # exception class
\end{pycode}

\code{make} creates a registered environment (a thin wrapper around
\code{gymnasium.make} that suppresses the ``out of date'' warning of
\code{-v0} ids); keyword arguments go to the environment constructor.
\code{max\_episode\_steps=N} sets the environment's own limit argument
(\code{EnvSpec.limit\_kwarg}) instead of adding a \code{TimeLimit} wrapper; it
raises \code{ValueError} if the limit argument is also given with a different
value. \code{make\_vec} creates \code{num\_envs} copies as one Gymnasium vector
environment with the same keyword arguments: \code{vectorization\_mode=None}
selects the native batched implementation (\code{EnvSpec.vector\_entry\_point})
when there is one and \code{gymnasium.vector.SyncVectorEnv} otherwise, and
\code{"sync"}, \code{"async"} and \code{"vector\_entry\_point"} force a mode.
\code{autoreset\_mode} (\code{"next\_step"}, \code{"same\_step"},
\code{"disabled"}, Gymnasium's spellings or \code{AutoresetMode} members) works
for every mode. \code{vector\_kwargs} (further arguments of the Sync or Async
class) and \code{wrappers} (applied to every copy) are only accepted by the
Sync and Async modes; for environments with per-agent reward arrays
(\code{EnvSpec.per\_agent\_rewards}, AJLATT) \code{TeamReward} is applied when
no \code{wrappers} are given.
\code{get\_spec} returns the registration record of an id and raises
\code{KeyError} for an unknown one. \code{list\_envs} returns the 18 registered
ids in the order of Table~\ref{tab:api-ids}. \code{register\_envs} registers all
ids with Gymnasium; it runs automatically on \code{import env\_lib} and is
idempotent. \code{ResetNeededError} is raised by every environment, including
the native vector environments, when \code{step()} or \code{render()} is
called before \code{reset()}; it subclasses both \code{RuntimeError} and
\code{gymnasium.error.ResetNeeded}. The environment classes below, and
\code{baseline\_policy}, \code{evaluate}, \code{rollout}, \code{describe} and
\code{EnvInfo}, are exported lazily by \pkg{env\_lib}, so optional
dependencies are imported only when a name is used.

\subsection{Common environment interface}

Every environment class implements the Gymnasium methods

% norun
\begin{pycode}
reset(*, seed=None, options=None) -> tuple[observation, dict]
step(action) -> tuple[observation, reward, terminated, truncated, dict]
render() -> np.ndarray | None        # (H, W, 3) uint8 in "rgb_array" mode
close()                              # idempotent
\end{pycode}

and has the attributes \code{action\_space}, \code{observation\_space},
\code{render\_mode}, \code{metadata} and \code{np\_random}. The \code{info}
dictionary always contains \code{"agent\_rewards"}, a \code{float64} array of
shape \code{(n\_agents,)}. Unknown keys of \code{options} are ignored with a
\code{UserWarning} (Section~\ref{sec:envlib-reset-options}).
Chapter~\ref{chap:envlib} describes the conventions.

The native vector environments (\code{KuramotoOscillatorVectorEnv},
\code{ConsensusVectorEnv}, \code{PowerGridVectorEnv}, \code{PlatoonVectorEnv})
implement the Gymnasium vector API through \code{BatchedVectorEnv}:

% norun
\begin{pycode}
reset(*, seed=None, options=None) -> tuple[observations, dict]
step(actions) -> tuple[observations, rewards, terminations, truncations, dict]
render() -> np.ndarray | None        # frame of copy 0
close()
\end{pycode}

with the attributes \code{num\_envs}, \code{single\_observation\_space},
\code{single\_action\_space}, \code{observation\_space}, \code{action\_space}
(batched), \code{autoreset\_mode}, \code{render\_mode}, \code{metadata} and
\code{np\_random} (one generator for all copies). \code{options} accepts
\code{"reset\_mask"} and the reset options of the single environment. Their
constructors take the keyword arguments of the single environment plus
\code{num\_envs} and \code{autoreset\_mode}. Rewards have shape
\code{(num\_envs,)}; every info value has a leading \code{num\_envs} dimension
and a mask \code{"\_key"}; \code{infos["agent\_rewards"]} has shape
\code{(num\_envs, n\_agents)}.

Both classes have the read-only properties \code{config},
\code{n\_followers}, \code{n\_agents}, \code{topology}, \code{scenario},

\code{BatchedVectorEnv} derives from \code{gymnasium.vector.VectorEnv} and
implements \code{reset} and \code{step} on top of the hooks: seeding of the
shared generator \code{self.np\_random}, the \code{"reset\_mask"} option
(removed before \code{options} reaches \code{\_reset\_envs}), action
validation (reshaping when the number of entries matches, \code{ValueError}
for a wrong size or for NaN and infinite values), the three autoreset modes
(\code{autoreset\_mode} also accepts \code{"NextStep"}-style names and
\code{gymnasium.vector.AutoresetMode} members), \code{infos["final\_obs"]} and
\code{infos["final\_info"]} in same-step mode, the \code{"\_key"} masks of
every info key and \code{ResetNeededError}. \code{\_step\_envs} returns arrays
of shape \code{(num\_envs,)} and a dictionary of arrays with a leading
\code{num\_envs} dimension; \code{active} marks the copies whose results are
used (under next-step autoreset the others are reset right afterwards).
\code{render()} returns \code{None} without a render mode and raises
\code{NotImplementedError} otherwise unless a subclass overrides it. A
subclass that serves as a \code{vector\_entry\_point} must accept the keyword
arguments of the single environment plus \code{num\_envs} and
\code{autoreset\_mode}, because \code{gymnasium.make\_vec} calls it as
\code{VectorClass(num\_envs=..., **registered\_kwargs, **user\_kwargs)}. A
minimal subclass:

\begin{pycode}
import numpy as np
from gymnasium import spaces
from env_lib.utils import BatchedVectorEnv

class Integrators(BatchedVectorEnv):
    """n agents with x' = u, reward -x_i^2 per agent, 50 steps per episode."""

    def __init__(self, num_envs=1, *, autoreset_mode="next_step", n_agents=4):
        obs = spaces.Box(-np.inf, np.inf, (n_agents, 1), np.float32)
        act = spaces.Box(-1.0, 1.0, (n_agents, 1), np.float32)
        super().__init__(num_envs, obs, act, autoreset_mode=autoreset_mode)
        self.x = np.zeros((self.num_envs, n_agents, 1))
        self.t = np.zeros(self.num_envs, dtype=np.int64)

    def _reset_envs(self, mask, options):
        self.x[mask] = self.np_random.uniform(-1.0, 1.0, self.x[mask].shape)
        self.t[mask] = 0

    def _step_envs(self, actions, active):
        self.x += 0.1 * np.clip(actions, -1.0, 1.0)
        self.t += 1
        agent_rewards = -self.x[..., 0] ** 2               # (num_envs, n_agents)
        terminated = np.zeros(self.num_envs, dtype=bool)
        infos = {"agent_rewards": agent_rewards}
        return agent_rewards.sum(axis=1), terminated, self.t >= 50, infos

    def _observe(self):
        return self.x.astype(np.float32)

envs = Integrators(8)
obs, infos = envs.reset(seed=0)
obs, rewards, terminated, truncated, infos = envs.step(-obs)
print(obs.shape, rewards.shape)             # (8, 4, 1) (8,)
print(infos["agent_rewards"].shape)         # (8, 4)
\end{pycode}

policies or trained algorithms. Rows are in the order references
(\code{"random"}, \code{"baseline"}), algorithms, policies, with
\code{kind} \code{"reference"}, \code{"algorithm"} or \code{"policy"}.
Evaluation uses only the first episode of every copy after a seeded reset,
in chunks of at most 64 episodes (reset with \code{eval\_seed},
\code{eval\_seed + 64}, \ldots), so every row meets the same episodes.
\code{compare} checks all arguments before it trains anything: it raises
\code{KeyError} for an unknown algorithm and \code{ValueError} for an
algorithm listed twice, one that does not support the environment's actions,
one without a preset when \code{total\_steps} is not given, a configuration
override that an algorithm rejects, invalid environment arguments or ones that
differ from a preset's, a policy name that repeats another row's name, empty or
repeated \code{seeds}, \code{eval\_seed=None}, or a non-positive
\code{n\_episodes}, \code{total\_steps} or \code{num\_envs}. The classical
controller row is omitted for environments without one; the replay buffers of
trained off-policy algorithms are released unless \code{keep\_replay=True}.

\subsection{The \texorpdfstring{\code{marl-train}}{marl-train} command line}\label{sec:api-marl-cli}

Module \pkg{marl\_algorithms.\_\_main\_\_}; Section~\ref{sec:marl-cli}. The

\code{argparse} parser.

\begin{shellcode}
marl-train list
marl-train presets
marl-train run ALGORITHM ENV_ID [--steps N] [--num-envs N] [--seed S]
               [--no-preset] [--set KEY=VALUE [KEY=VALUE ...]]
               [--env-kwarg KEY=VALUE [KEY=VALUE ...]] [--eval-episodes N]
               [--reports N] [--save PATH] [--csv PATH] [--threads N]
marl-train compare ENV_ID [--algos ALGO [ALGO ...]] [--seeds S [S ...]]
                   [--steps N] [--num-envs N] [--episodes N] [--eval-seed S]
                   [--set KEY=VALUE [KEY=VALUE ...]]
                   [--env-kwarg KEY=VALUE [KEY=VALUE ...]] [--markdown]
                   [--csv PATH] [--save-dir DIR] [--threads N]
marl-train evaluate CHECKPOINT ENV_ID [--episodes N] [--seed S]
                    [--env-kwarg KEY=VALUE [KEY=VALUE ...]]
\end{shellcode}

Defaults: \code{run} uses the preset's steps and copies (100\,000 and 16
without a preset), \code{-{}-seed 0}, \code{-{}-eval-episodes 64},
\code{-{}-reports 10} and \code{-{}-threads 1}; \code{compare} uses every
algorithm with a preset, \code{-{}-seeds 0}, the presets' budgets,
\code{-{}-episodes 64}, \code{-{}-eval-seed 1} and \code{-{}-threads 1};
\code{evaluate} uses \code{-{}-episodes 64} and \code{-{}-seed 1}.
\code{KEY=VALUE} values are parsed as Python literals (plain text otherwise).
Command-line usage errors (including a malformed \code{KEY=VALUE} pair and a
non-positive count), and an unknown environment, algorithm, configuration
field or checkpoint, invalid environment arguments or configuration values,
an algorithm that does not support the environment's actions, or (for
\code{compare}) one without a preset and without \code{-{}-steps}, end the
command before any training with a message on standard error and exit status
2. Without PyTorch, every sub-command reports that PyTorch is not installed
and exits with status 1.
